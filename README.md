# 🃏 Poker Timer

Веб-приложение для управления покерной игрой с выводом таймера и информации на телевизор.

## 📋 Возможности

- ⏱ **Таймер блайндов** с настраиваемым временем и структурой
- 👥 **Управление игроками** — добавление, выбывание, ре-энтри, аддоны, стеки
- 🎰 **Рассадка по столам** — рандомная и ручная, поддержка нескольких столов
- 📺 **Экран для ТВ** — большой таймер, блайнды, рассадка, комбинации
- 📱 **Мобильное управление** — управление через телефон в локальной сети
- 🔊 **Звуковые сигналы** — предупреждение о повышении блайндов
- 🌙 **Тёмная/светлая тема**
- 🔄 **Синхронизация между устройствами** через WebSocket
- 💾 **Автосохранение** — состояние сохраняется на сервере

## 📱 Как использовать

### 1. Настройка игры
1. Откройте главную страницу → **Настройка игры**
2. Установите время уровня (например, 12 минут)
3. Настройте блайнды (или используйте стандартные)
4. Добавьте всех игроков с их бай-инами
5. Укажите количество столов и мест

### 2. Рассадка
- Нажмите **🎲 Рандомная рассадка** для автоматического распределения
- Или назначьте столы и места вручную

### 3. Запуск
1. На ноутбуке откройте `/tv` — это экран для телевизора
2. Разверните на весь экран (F11)
3. С телефона откройте `/control` — это пульт управления
4. Нажмите **▶ Начать игру**

### 4. Во время игры

**С телефона (пульт управления):**
- ⏸ Пауза / ▶ Продолжить
- ➡️ Пропустить уровень блайндов
- ❌ Отметить игрока как выбывшего
- 💰 Добавить стек или аддон
- 🔄 Ре-энтри для выбывшего игрока

**На экране ТВ видно:**
- ⏱ Большой таймер (мигает красным в последнюю минуту)
- 📊 Текущие и следующие блайнды
- 👥 Список игроков с фишками
- 🎰 Рассадка по столам
- 🃏 Шпаргалка с комбинациями (по кнопке)

## 🌐 Доступ с телефона

Чтобы управлять с телефона:

1. **Создайте точку доступа** с ноутбука:
   - **Windows**: Параметры → Сеть и Интернет → Мобильный хот-спот → Включить
   - **macOS**: Системные настройки → Общий доступ → Интернет-доступ

2. Подключите телефон к этой сети

3. Узнайте IP ноутбука:
   - **Windows**: `ipconfig` → найдите IPv4 адрес (например 192.168.137.1)
   - **macOS**: `ifconfig` или в настройках сети

4. На телефоне откройте: `http://[IP-ноутбука]:3000/control`

**Все устройства синхронизированы в реальном времени!**

## 🔊 Звуковые сигналы

- **За 30 секунд** до повышения — тройной звуковой сигнал
- **Последняя минута** — таймер становится красным и пульсирует
- **Каждые 5 секунд** в последние 10 секунд — одиночный сигнал
- **Повышение уровня** — восходящий мелодичный сигнал

## 🔧 Как работает синхронизация

Приложение использует **двухуровневую синхронизацию**:

1. **WebSocket** — синхронизация между разными устройствами (ноутбук + телефон)
   - Бэкенд на FastAPI хранит состояние игры
   - Все изменения рассылаются в реальном времени через WebSocket
   
2. **BroadcastChannel** — синхронизация между вкладками одного браузера
   - Работает даже если бэкенд недоступен
   - Полезно для тестирования

## ⚙️ Настройка блайндов

Стандартная структура (20 уровней):
| Уровень | SB | BB |
|---------|------|------|
| 1 | 25 | 50 |
| 2 | 50 | 100 |
| 3 | 75 | 150 |
| ... | ... | ... |

Можно изменить в разделе **Настройки → Блайнды → Редактировать**.

## 🐛 Решение проблем

### Не работает синхронизация с телефоном
- Убедитесь что телефон и ноутбук в одной сети
- Проверьте что сервер запущен (должен быть виден в консоли)
- Попробуйте перезагрузить страницу на телефоне

### Звуки не работают
- Проверьте что звук включён в браузере
- Некоторые браузеры блокируют автовоспроизведение — нажмите на страницу

### Поля ввода не работают
- Обновите страницу (F5)
- Очистите кэш браузера (Ctrl+Shift+R)
