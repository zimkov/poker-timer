## Как запустить

### Вариант 1: Автоматический (рекомендуется)

**Windows:**
```
Дважды кликните на start-windows.bat
```

**macOS/Linux:**
```bash
chmod +x start.sh
./start.sh
```

Скрипт автоматически:
1. Проверит наличие Node.js и Python
2. Установит все зависимости
3. Соберёт фронтенд
4. Запустит сервер на порту 3000
5. Откроет браузер

### Вариант 2: Ручной

```bash
# 1. Установить зависимости фронтенда
npm install

# 2. Собрать фронтенд
npm run build

# 3. Установить зависимости бэкенда
cd backend
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
cd ..

# 4. Запустить сервер
cd backend
python main.py
```

## Как использовать

### 1. На компьютере (ноутбук)
1. Откройте http://localhost:3000
2. Перейдите в "Настройка игры"
3. Добавьте игроков
4. Настройте блайнды
5. Перейдите в "Экран для ТВ" → http://localhost:3000/tv
6. Нажмите F11 для полноэкранного режима

### 2. С телефона
1. Подключитесь к той же сети Wi-Fi
2. Откройте http://[IP-ноутбука]:3000/control
3. Управляйте игрой:
   - Добавляйте игроков
   - Отмечайте выбывших
   - Добавляйте стеки/аддоны
   - Управляйте таймером

### 3. Синхронизация
- Все изменения синхронизируются в реальном времени
- Таймер тикает одновременно на всех устройствах
- Можно открыть несколько экранов ТВ на разных мониторах

## Решение проблем

### Не работает синхронизация с телефоном
1. Убедитесь что телефон и ноутбук в одной сети
2. Проверьте что сервер запущен (в консоли должно быть "Сервер запущен!")
3. Попробуйте перезагрузить страницу на телефоне
4. Проверьте firewall — порт 3000 должен быть открыт

### Поля ввода не реагируют
1. Обновите страницу (Ctrl+Shift+R или Cmd+Shift+R)
2. Очистите кэш браузера
3. Попробуйте другой браузер

### Звуки не работают
1. Проверьте что звук включён в браузере
2. Кликните на страницу (некоторые браузеры блокируют звук до первого клика)

### Таймер не тикает
1. Нажмите "Начать игру"
2. Проверьте что не стоит на паузе
3. Обновите страницу

## Технологии

- **Frontend:** React + TypeScript + Vite + Tailwind CSS + Zustand
- **Backend:** FastAPI + WebSocket
- **Sync:** WebSocket (между устройствами) + BroadcastChannel (между вкладками)

## Поддержка

Если что-то не работает:
1. Проверьте что Node.js и Python установлены
2. Попробуйте удалить node_modules и запустить скрипт снова
3. Проверьте консоль браузера (F12) на ошибки
4. Проверьте консоль сервера на ошибки
